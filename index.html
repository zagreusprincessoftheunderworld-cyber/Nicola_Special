Funkcja liniowa: f(x) = ax + b

⚡ Przesuń suwaki i zobacz jak działa wykres

  • a > 0 → funkcja rosnąca (prosta idzie w górę).
  • a < 0 → funkcja malejąca (prosta idzie w dół).
  • b → punkt przecięcia z osią OY (żółta kropka).
  • Miejsce zerowe → punkt przecięcia z osią OX (zielona kropka, f(x) = 0).

Wskaż wykres funkcji liniowej f(x) = ax + b, gdzie a > 0 i b < 0.
Krok po kroku: Skoro a > 0, prosta rośnie (idzie w górę). Skoro b < 0, przecina oś OY poniżej zera. Pasuje wykres B.
Zadanie 6.7Odpowiedź: D (m = 4)
Punkt A = (0, 1) leży na wykresie f(x) = (m - 2)x + m - 3. Oblicz m.
Krok po kroku: Podstawiamy x = 0 oraz y = 1: 1 = (m - 2)·0 + m - 3 → 1 = m - 3 → m = 4.
