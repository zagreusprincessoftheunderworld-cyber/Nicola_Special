Wszystkie najważniejsze wzory, interaktywne wykresy oraz gotowe rozwiązania zadań z arkuszy.

📐 Zasady: f(x) = ax + b

  • Monotoniczność (współczynnik a):
    a > 0 → funkcja rosnąca (idzie w górę)
    a < 0 → funkcja malejąca (idzie w dół)
    a = 0 → funkcja stała (pozioma)
  • Przecięcie z osią OY (współczynnik b):
    Punkt (0, b). Nad osią OX → b > 0; pod osią → b < 0.
  • Miejsce zerowe (x₀):
    Podstaw f(x) = 0 → ax + b = 0 → x₀ = -b / a.
  • Symetrie wykresu:
    Względem osi OX: g(x) = -f(x) (zmieniasz wszystkie znaki)
    Względem punktu (0,0): g(x) = -f(-x)
