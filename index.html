Funkcja liniowa (6.6–6.17)
Nierówności liniowe
Nierówności kwadratowe
Ułamki, pierwiastki i logarytmy

Zapamiętaj w 30 sekund: f(x) = ax + b

• a > 0 → funkcja rosnąca (prosta idzie w górę). a < 0 → funkcja malejąca (prosta idzie w dół).

• b → punkt przecięcia z osią OY. Nad osią OX → b > 0, pod osią OX → b < 0.

• Miejsce zerowe → podstaw f(x) = 0 i wylicz x (punkt przecięcia z osią OX).

Zadanie 6.6Odpowiedź: B
Wskaż wykres funkcji liniowej f(x) = ax + b, gdzie a > 0 i b < 0.
Rozwiązanie: Skoro a > 0, prosta rośnie (idzie w górę). Skoro b < 0, przecina oś OY poniżej zera. Pasuje rysunek B.
Zadanie 6.7Odpowiedź: D (m = 4)
Punkt A = (0, 1) leży na wykresie funkcji liniowej f(x) = (m - 2)x + m - 3. Oblicz m.
Rozwiązanie: Podstawiamy x = 0 oraz y = 1 do wzoru: 1 = (m - 2)·0 + m - 3 → 1 = m - 3 → m = 4.
Zadanie 6.8Odpowiedź: B (a < 0 i b > 0)
Na rysunku prosta opada w dół i przecina oś OY powyżej zera. Jakie znaki mają a i b?
Rozwiązanie: Prosta opada w dół (funkcja malejąca) → a < 0. Przecina oś OY nad osią OX → b > 0.
Zadanie 6.9Odpowiedź: B. m ∈ (-2, 2)
Funkcja liniowa f(x) = (m² - 4)x + 2 jest malejąca, gdy...
Rozwiązanie: Funkcja jest malejąca, gdy współczynnik przy x jest ujemny: m² - 4 < 0 → m² < 4 → m leży między -2 a 2: m ∈ (-2, 2).
Zadanie 6.10Odpowiedź: A. f(x) = -1/3 x + 7/3
Wiadomo, że f(1) = 2 oraz punkt P = (-2, 3) należy do wykresu. Wyznacz wzór funkcji f.
Rozwiązanie: Mamy dwa punkty: (1, 2) i (-2, 3). Liczymy a = (3 - 2) / (-2 - 1) = -1/3. Podstawiamy (1, 2) do y = -1/3x + b: 2 = -1/3 + b → b = 7/3.
Zadanie 6.11Odpowiedź: A. ⟨-10, 2⟩
Funkcja f(x) = 3x - 4 jest określona dla x ∈ ⟨-2, 2⟩. Wyznacz zbiór wartości.
Rozwiązanie: Podstawiamy krańce przedziału: f(-2) = 3(-2) - 4 = -10 oraz f(2) = 3(2) - 4 = 2. Przedział jest domknięty: ⟨-10, 2⟩.
Zadanie 6.12Odpowiedź: D (a > 0 i b < 0)
Funkcja f(x) = ax + b jest rosnąca i ma dodatnie miejsce zerowe.
Rozwiązanie: Rosnąca → a > 0. Aby prosta idąca w górę przecięła oś OX na prawo od zera, musi zaczynać się pod osią OX → b < 0.
Zadanie 6.13Odpowiedź: B (m = 0)
Na wykresie f(x) = (m - 1)x + 3 leży punkt S = (5, -2). Oblicz m.
Rozwiązanie: Podstawiamy x = 5 i y = -2: -2 = (m - 1)·5 + 3 → -5 = 5(m - 1) → m - 1 = -1 → m = 0.
Zadanie 6.14Odpowiedź: C (b = -8/3)
Funkcja f(x) = 2x + b ma takie samo miejsce zerowe, jakie ma g(x) = -3x + 4. Oblicz b.
Rozwiązanie: Miejsce zerowe g: -3x + 4 = 0 → x = 4/3. Podstawiamy x = 4/3 do f(x) = 0: 2·(4/3) + b = 0 → 8/3 + b = 0 → b = -8/3.
Zadanie 6.15Odpowiedź: B. g(x) = 2x - 2
Na rysunku f(x) = -2x + 2. Wykres g jest symetryczny do f względem osi poziomej (OX).
Rozwiązanie: Symetria względem osi OX zmienia znak całego wzoru: g(x) = -f(x) = -(-2x + 2) = 2x - 2.
Zadanie 6.16Odpowiedź: A. m < -2/3
Miejsce zerowe funkcji f(x) = x + 3m jest większe od 2 dla każdego m spełniającego warunek...
Rozwiązanie: Miejsce zerowe: x + 3m = 0 → x = -3m. Warunek: -3m > 2. Dzielimy przez -3 (zmieniamy znak nierówności!): m < -2/3.
Zadanie 6.17Odpowiedź: A. g(x) = 2x + 2
f(0) = -2 i f(1) = 0 (czyli f(x) = 2x - 2). Wykres g jest symetryczny względem początku układu (0, 0).
Rozwiązanie: Symetria względem (0, 0) zmienia znak przy x oraz przy całym wzorze: g(x) = -f(-x) = -(2(-x) - 2) = 2x + 2.

Główna zasada dla nierówności liniowych

Rozwiązujesz jak zwykłe równanie, ALE: gdy dzielisz lub mnożysz obie strony przez liczbę ujemną — odwracasz znak nierówności (< zmienia się na >).

Zadanie 5.42Odpowiedź: B (6)
Podaj największą liczbę całkowitą spełniającą nierówność: x/4 - √3 < 0
Rozwiązanie: x/4 < √3 → x < 4√3. Szacujemy: √3 ≈ 1,73, więc 4 · 1,73 = 6,92. Największa liczba całkowita mniejsza od 6,92 to 6.
