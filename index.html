Funkcja liniowa (Zadania 6.6 – 6.17)

⚡ Wzór ogólny: f(x) = ax + b

  • a > 0 → funkcja rosnąca (idzie w górę). a < 0 → malejąca (idzie w dół).
  • b → punkt przecięcia z osią OY (nad osią OX: b > 0, pod osią: b < 0).
  • Miejsce zerowe → podstaw f(x) = 0 i wylicz x (punkt na osi OX).
Zadanie 6.6Odpowiedź: B
Wskaż wykres funkcji liniowej f(x) = ax + b, gdzie a > 0 i b < 0.
Krok po kroku: Skoro a > 0, prosta rośnie (idzie w górę). Skoro b < 0, przecina oś OY poniżej zera. Pasuje wyłącznie wykres B.
Zadanie 6.7Odpowiedź: D (m = 4)
Punkt A = (0, 1) leży na wykresie f(x) = (m - 2)x + m - 3. Oblicz m.
Krok po kroku: Podstawiamy x = 0 oraz y = 1: 1 = (m - 2)·0 + m - 3 → 1 = m - 3 → m = 4.
Zadanie 6.8Odpowiedź: B (a < 0 i b > 0)
Na rysunku prosta opada w dół i przecina oś OY powyżej zera. Jakie znaki mają a i b?
Krok po kroku: Prosta opada w dół (malejąca) → a < 0. Przecina oś OY nad osią OX → b > 0.
Zadanie 6.9Odpowiedź: B. m ∈ (-2, 2)
Funkcja liniowa f(x) = (m² - 4)x + 2 jest malejąca, gdy...
Krok po kroku: Funkcja jest malejąca, gdy współczynnik przy x jest ujemny: m² - 4 < 0 → m² < 4 → m ∈ (-2, 2).
Zadanie 6.10Odpowiedź: A. f(x) = -1/3 x + 7/3
Wiadomo, że f(1) = 2 oraz punkt P = (-2, 3) należy do wykresu. Wyznacz wzór funkcji.
