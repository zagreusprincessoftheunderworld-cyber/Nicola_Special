1. Funkcja liniowa: f(x) = ax + b (Zadania 6.6 – 6.17)

Zasady do zapamiętania:
• a > 0 → funkcja rosnąca (idzie w górę); a < 0 → malejąca (idzie w dół).
• b → punkt przecięcia z osią pionową OY (nad osią OX: b > 0, pod osią OX: b < 0).
• Miejsce zerowe → podstaw f(x) = 0 i wylicz x. Symetria względem OX: g(x) = -f(x).
Zadanie 6.6Odpowiedź: B
Wskaż wykres funkcji liniowej f(x) = ax + b, gdzie a > 0 i b < 0.
a > 0 oznacza, że prosta rośnie (idzie w górę). b < 0 oznacza, że przecina oś OY poniżej zera. Pasuje wykres B.
Zadanie 6.7Odpowiedź: D (m = 4)
Punkt A = (0, 1) leży na wykresie f(x) = (m - 2)x + m - 3. Oblicz m.
Podstawiamy x = 0 oraz y = 1: 1 = (m - 2)·0 + m - 3 → 1 = m - 3 → m = 4.
Zadanie 6.8Odpowiedź: B (a < 0 i b > 0)
Na rysunku prosta opada w dół i przecina oś OY powyżej zera. Jakie znaki mają a i b?
Prosta opada w dół (funkcja malejąca) → a < 0. Przecina oś OY nad osią OX → b > 0.
Zadanie 6.9Odpowiedź: B. m ∈ (-2, 2)
Funkcja liniowa f(x) = (m² - 4)x + 2 jest malejąca, gdy...
Funkcja maleje, gdy współczynnik przy x jest ujemny: m² - 4 < 0 → m² < 4 → m ∈ (-2, 2).
Zadanie 6.10Odpowiedź: A. f(x) = -1/3 x + 7/3
Wiadomo, że f(1) = 2 oraz punkt P = (-2, 3) należy do wykresu. Wyznacz wzór funkcji.
Mamy dwa punkty: (1, 2) i (-2, 3). Nachylenie a = (3 - 2) / (-2 - 1) = -1/3. Podstawiamy (1, 2): 2 = -1/3·1 + b → b = 7/3.
Zadanie 6.11Odpowiedź: A. ⟨-10, 2⟩
Funkcja f(x) = 3x - 4 jest określona dla x ∈ ⟨-2, 2⟩. Wyznacz zbiór wartości.
Liczymy wartości na krańcach przedziału: f(-2) = 3(-2) - 4 = -10 oraz f(2) = 3(2) - 4 = 2. Zbiór wartości: ⟨-10, 2⟩.
Zadanie 6.12Odpowiedź: D (a > 0 i b < 0)
Funkcja f(x) = ax + b jest rosnąca i ma dodatnie miejsce zerowe.
Rosnąca → a > 0. Aby prosta idąca w górę przecięła oś OX na prawo od zera, musi zaczynać się pod osią OX → b < 0.
Zadanie 6.13Odpowiedź: B (m = 0)
Na wykresie f(x) = (m - 1)x + 3 leży punkt S = (5, -2). Oblicz m.
Podstawiamy x = 5, y = -2: -2 = (m - 1)·5 + 3 → -5 = 5(m - 1) → m - 1 = -1 → m = 0.
Zadanie 6.14Odpowiedź: C (b = -8/3)
Funkcja f(x) = 2x + b ma takie samo miejsce zerowe, jakie ma g(x) = -3x + 4. Oblicz b.
Miejsce zerowe g: -3x + 4 = 0 → x = 4/3. Podstawiamy do f: 2·(4/3) + b = 0 → b = -8/3.
Zadanie 6.15Odpowiedź: B. g(x) = 2x - 2
Na rysunku f(x) = -2x + 2. Wykres g jest symetryczny względem osi poziomej (OX).
Symetria względem osi OX zmienia znak całego wzoru: g(x) = -(-2x + 2) = 2x - 2.
Zadanie 6.16Odpowiedź: A. m < -2/3
Miejsce zerowe funkcji f(x) = x + 3m jest większe od 2 dla każdego m spełniającego...
Miejsce zerowe: x = -3m > 2. Dzielimy przez -3 (odwracamy znak nierówności!) → m < -2/3.
Zadanie 6.17Odpowiedź: A. g(x) = 2x + 2
f(0) = -2 i f(1) = 0 (czyli f(x) = 2x - 2). Wykres g jest symetryczny względem (0, 0).
Symetria względem (0, 0) zmienia znak przy x i przy całym wzorze: g(x) = -f(-x) = -(2(-x) - 2) = 2x + 2.

2. Nierówności liniowe i kwadratowe

Zasady do zapamiętania:
• Gdy dzielisz lub mnożysz nierówność przez liczbę ujemną, znak nierówności (< / >) zawsze się odwraca!
• <, > → kółko otwarte i nawias ( ); ≤, ≥ → kółko zamalowane i nawias ⟨ ⟩.
• Kwadratowe: a > 0 (ramiona w górę ∪) → > 0 na zewnątrz; a < 0 (ramiona w dół ∩) → > 0 między pierwiastkami.
Zadanie 5.42 (Liniowa)Odpowiedź: B (6)
Podaj największą liczbę całkowitą spełniającą nierówność: x/4 - √3 < 0
x/4 < √3 → x < 4√3. Szacujemy: √3 ≈ 1,73, więc 4 · 1,73 = 6,92. Największa liczba całkowita mniejsza od 6,92 to 6.
Zadanie 5.7 (Liniowa z ułamkami)Odpowiedź: B (2)
Podaj najmniejszą liczbę całkowitą spełniającą nierówność: 3/8 + x/6 < 5x/12
Mnożymy całość przez wspólny mianownik 24: 9 + 4x < 10x → 9 < 6x → x > 1,5. Najmniejsza całkowita to 2.
