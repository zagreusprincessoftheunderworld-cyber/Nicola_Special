Ściągawka przed sprawdzianem

Wybierz temat, przesuń suwaki na wykresie i powtórz gotowe zadania.

Zasady: f(x) = ax + b

  • a > 0 → funkcja rosnąca (w górę); a < 0 → malejąca (w dół).
  • b → punkt na osi OY (żółty punkt).
  • Miejsce zerowe x₀ → punkt na osi OX (zielony punkt, ax + b = 0).
Nachylenie a = 1
Przesunięcie b = -1
Rosnąca (a > 0) • b = -1 • x₀ = 1
Zad. 6.6Odp: B
Wykres f(x) = ax + b, gdzie a > 0 i b < 0.
a > 0 (idzie w górę) oraz b < 0 (przecina oś Y pod zerem) → rysunek B.
Zad. 6.7Odp: D (m = 4)
Punkt A = (0, 1) leży na f(x) = (m - 2)x + m - 3.
Podstaw x = 0, y = 1: 1 = 0 + m - 3 → m = 4.
Zad. 6.8Odp: B (a < 0, b > 0)
Prosta na rysunku opada w dół i przecina oś Y nad zerem.
Opada w dół → a < 0; przecina oś Y nad OX → b > 0.
Zad. 6.9Odp: B. m ∈ (-2, 2)
f(x) = (m² - 4)x + 2 jest malejąca, gdy...
m² - 4 < 0 → m² < 4 → m ∈ (-2, 2).
Zad. 6.10Odp: A. f(x) = -1/3 x + 7/3
f(1) = 2 oraz punkt P = (-2, 3) na wykresie.
a = (3 - 2)/(-2 - 1) = -1/3. Z punktu (1, 2): 2 = -1/3 + b → b = 7/3.
Zad. 6.11Odp: A. ⟨-10, 2⟩
Zbiór wartości f(x) = 3x - 4 dla x ∈ ⟨-2, 2⟩.
f(-2) = -10, f(2) = 2 → przedział ⟨-10, 2⟩.
Zad. 6.12Odp: D (a > 0, b < 0)
f(x) = ax + b jest rosnąca i ma dodatnie miejsce zerowe.
Rosnąca → a > 0; przecina OX po prawej stronie → startuje z dołu, więc b < 0.
Zad. 6.13Odp: B (m = 0)
Punkt S = (5, -2) leży na f(x) = (m - 1)x + 3.
-2 = 5(m - 1) + 3 → -5 = 5(m - 1) → m = 0.
Zad. 6.14Odp: C (b = -8/3)
f(x) = 2x + b ma takie samo miejsce zerowe jak g(x) = -3x + 4.
Zero g: x = 4/3. Podstawiamy do f: 2(4/3) + b = 0 → b = -8/3.
Zad. 6.15Odp: B. g(x) = 2x - 2
f(x) = -2x + 2, wykres g symetryczny względem osi OX.
Symetria względem OX zmienia znaki: g(x) = -(-2x + 2) = 2x - 2.
Zad. 6.16Odp: A. m < -2/3
Miejsce zerowe f(x) = x + 3m jest większe od 2.
x = -3m > 2 → dzielimy przez -3 (zmiana znaku!) → m < -2/3.
Zad. 6.17Odp: A. g(x) = 2x + 2
f(x) = 2x - 2, wykres g symetryczny względem (0, 0).
g(x) = -f(-x) = -(2(-x) - 2) = 2x + 2.

Zasady nierówności liniowych

  • Przenieś x na lewo, liczby na prawo (zmień znak przy przenoszeniu).
  • PUŁAPKA: Gdy dzielisz lub mnożysz przez liczbę ujemną, odwróć znak (< na >)!
  • Nawiasy: <, > → kółko otwarte ( ); ≤, ≥ → kółko zamalowane ⟨ ⟩.
