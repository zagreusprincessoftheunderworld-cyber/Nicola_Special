📐 Wzór funkcji liniowej: f(x) = ax + b

  • Współczynnik a (nachylenie):
    a > 0 → funkcja rosnąca (idzie w górę)
    a < 0 → funkcja malejąca (idzie w dół)
    a = 0 → funkcja stała (pozioma)
  • Współczynnik b (żółty punkt):
    Punkt przecięcia z osią pionową OY: (0, b).
  • Miejsce zerowe x₀ (zielony punkt):
    Punkt na osi OX, gdzie f(x) = 0 → x₀ = -b / a.
  • Symetrie wykresu:
    Względem osi OX: g(x) = -f(x)
    Względem punktu (0,0): g(x) = -f(-x)
a = 1
b = -1
Rosnąca (a > 0) • b = -1 • x₀ = 1
Zadania ze zbioru (6.6 – 6.17)
Zadanie 6.6Odpowiedź: B
Wskaż wykres funkcji liniowej f(x) = ax + b, gdzie a > 0 i b < 0.
a > 0 (prosta idzie w górę) oraz b < 0 (przecina oś OY poniżej zera) → rysunek B.
Zadanie 6.7Odpowiedź: D (m = 4)
Punkt A = (0, 1) leży na wykresie f(x) = (m - 2)x + m - 3. Oblicz m.
Podstawiamy x = 0, y = 1: 1 = (m - 2)·0 + m - 3 → 1 = m - 3 → m = 4.
Zadanie 6.8Odpowiedź: B (a < 0 i b > 0)
Na rysunku prosta opada w dół i przecina oś OY powyżej zera. Jakie znaki mają a i b?
Prosta opada w dół (funkcja malejąca) → a < 0. Przecina OY nad osią OX → b > 0.
Zadanie 6.9Odpowiedź: B. m ∈ (-2, 2)
Funkcja liniowa f(x) = (m² - 4)x + 2 jest malejąca, gdy...
Funkcja maleje, gdy współczynnik przy x jest ujemny: m² - 4 < 0 → m² < 4 → m ∈ (-2, 2).
