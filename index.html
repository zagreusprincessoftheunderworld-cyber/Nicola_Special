4 działy, interaktywne wykresy oraz wszystkie rozwiązane zadania.

📐 Funkcja liniowa: f(x) = ax + b

  • a > 0 → rosnąca (w górę); a < 0 → malejąca (w dół).
  • b → przecięcie z osią OY (żółty punkt).
  • Miejsce zerowe x₀ → punkt na OX (zielony, ax + b = 0).
  • Symetria OX: g(x) = -f(x). Symetria (0,0): g(x) = -f(-x).
a = 1
b = -1
Rosnąca (a > 0) • b = -1 • x₀ = 1

🎯 Nierówności liniowe i kwadratowe

  • Liniowe: Przy dzieleniu przez liczbę ujemną odwróć znak (< na >)!
  • <, > → ( ); ≤, ≥ → ⟨ ⟩.
  • Kwadratowe: Po prawej 0, znajdź x₁, x₂. a > 0 (∪): > 0 na zewnątrz; a < 0 (∩): > 0 w środku.
a = -1
x₂ = 2
a < 0 (w dół): > 0 wewnątrz (0, 2)

⚙️ Równania wymierne, kwadratowe i wielomianowe

  • Ułamek = 0 gdy licznik = 0 i mianownik ≠ 0 (zawsze sprawdź dziedzinę!).
  • Wzory Viète’a: suma x₁ + x₂ = -b/a, iloczyn x₁ · x₂ = c/a.

🔑 Moduły i logarytmy (Kartkówka nr 1)

  • Moduł |w|: Gdy w środku ujemne → zmień znaki na przeciwne.
  • Logarytmy: logₐ x + logₐ y = logₐ(xy) | logₐ x - logₐ y = logₐ(x/y) | a^(logₐ b) = b.
